# Changelog

## 0.2.0 — 2026-10-16

- Renamed the product OpenAI Cost Tracker while retaining its installed extension identity.
- Added global status-bar and Activity Bar access in empty, restricted and virtual desktop windows.
- Added application-scoped configuration and shared per-user or configured private storage.
- Coordinated indexing, billing, currency refreshes and credential invalidation across windows.
- Added guarded all-profile installation using VS Code's native operation.
- Redesigned the dashboard around Overview, Daily, Monthly and Tokens tabs, following the editor theme.
- Added real daily trends, keyboard navigation, persistence, accessible tables and explicit coverage gaps.
- Added portable project-local development tooling, browser verification and isolated VS Code host checks.
- Preserved the repository's original MPL-2.0 license.

## 0.1.0 — 2026-10-16

Initial local delivery before this repository was connected:

- Codex token-log accounting and OpenAI organization Costs integration.
- USD/INR, cache-read/cache-write accounting, output/reasoning separation and long-context rates.
- Daily and monthly views with historical month selection.
- Dated rate cards, unknown/unpriced indicators and accounting JSON export.

Local token figures remain estimates. Organization billing needs a user-supplied Admin key; ordinary ChatGPT conversations and subscription charges are outside that API's coverage.
